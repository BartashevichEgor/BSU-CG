# BSU-CG

Лабораторные работы по дисциплине «Компьютерная графика».

| Работа | Тема | Запуск |
| --- | --- | --- |
| `lab1` | Цветовые модели CMYK, RGB, HLS | `http://localhost:8000/lab1/` |
| `lab2` | Обработка изображений и гистограммы | `http://localhost:8000/lab2/` |
| `lab3` | Базовые растровые алгоритмы | `http://localhost:8000/lab3/` |

Все приложения написаны на HTML, CSS и JavaScript без сторонних библиотек. Для запуска из корня репозитория:

```powershell
python -m http.server 8000
```
