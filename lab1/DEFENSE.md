# Защита ЛР №1: CMYK — RGB — HLS

## Как показать работу за 2 минуты

1. Выбрать пресет «Красный»: показать RGB(255,0,0), CMYK(0,100,100,0), HLS(0,50,100).
2. Изменить R в RGB. Сказать: «RGB — внутреннее точное состояние; CMYK и HLS пересчитываются из него, а не друг из друга». 
3. Изменить K в CMYK. Сказать: «При K=100% отдельная ветка возвращает чёрный и не делит на 1−K».
4. Выбрать серый, сдвинуть L к 0% и 100%. Сказать: «У ахроматического цвета Δ=0, S=0, H не определён; интерфейс сохраняет последнее H, чтобы ползунок не прыгал».
5. Ввести −1 или 300 в RGB: показать ограничение диапазона.

## Алгоритмы, которые надо уметь объяснить

### RGB → CMYK

```text
r = R / 255; g = G / 255; b = B / 255
K = 1 - max(r, g, b)
if K == 1: return (0, 0, 0, 1)
C = (1 - r - K) / (1 - K)
M = (1 - g - K) / (1 - K)
Y = (1 - b - K) / (1 - K)
```

### CMYK → RGB

```text
r = (1 - C) * (1 - K)
g = (1 - M) * (1 - K)
b = (1 - Y) * (1 - K)
R = round(255 * r), аналогично G и B
```

### RGB → HLS

```text
M = max(r, g, b); m = min(r, g, b); d = M - m
L = (M + m) / 2
if d == 0: S = 0; H не определён
else:
  S = d / (1 - abs(2*L - 1))
  H вычисляется по каналу, равному M, затем приводится к 0…360°
```

### HLS → RGB

```text
if S == 0: r = g = b = L
иначе:
  q = L*(1+S), если L < 0.5; иначе L+S-L*S
  p = 2*L - q
  r = hueToRgb(p,q,H+1/3); g = hueToRgb(p,q,H); b = hueToRgb(p,q,H-1/3)
```

## Частые вопросы преподавателя

**Почему CMYK → HLS не делается формулой напрямую?** Обе модели надёжно переводятся через нормированный RGB; так меньше формул и нет округления между промежуточными UI-полями.

**Почему у серого H не ноль?** Математически оттенка нет. Ноль — только выбранное представление. В UI хранится последний осмысленный H.

**Почему RGB округляется до целого, а остальные значения до 0,1?** Это диапазон задания: экранные каналы дискретны 0…255, а проценты и угол удобнее показывать точнее.

**Где исключён дрейф?** Обработчик меняет RGB из активной модели и обновляет две остальные; обратное преобразование активной модели не используется как новое состояние.
