# Лабораторная работа №1: CMYK - RGB - HLS

Веб-приложение показывает один цвет сразу в трёх моделях. Формулы реализованы вручную в `colorMath.js`; этот файл не зависит от DOM и поэтому удобен для разбора и тестирования на защите.

## Запуск

Откройте `index.html` в современном браузере. Сервер и установка зависимостей не нужны. Для корректной работы кнопки копирования браузер может потребовать открыть файл через локальный сервер, например `python -m http.server 8000` и перейти на `http://localhost:8000`.

## Проверка

1. Выберите готовый цвет или точку в палитре; все поля обновятся.
2. Сдвиньте любой ползунок RGB, CMYK или HLS; две другие модели пересчитаются сразу.
3. Введите точное число в поле. Значения вне диапазона ограничиваются с уведомлением.
4. Для чёрного, белого и серого обратите внимание: H сохраняется в интерфейсе, а S равна 0.

Диапазоны: RGB 0..255, CMYK 0..100 %, HLS: H 0..360°, L и S 0..100 %.
