# Лабораторная работа №2 — вариант 1

Веб-приложение реализует поэлементную обработку, линейное контрастирование и эквализацию гистограммы на чистых HTML5 Canvas/ImageData, без библиотек обработки изображений.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей и сервер не требуются. Результаты рассчитываются каждый раз из неизменённого исходного `ImageData`, поэтому округления предыдущих действий не накапливаются.

## Проверка

1. Выберите любой встроенный образец либо загрузите PNG/JPEG.
2. Выберите метод и измените параметр: справа мгновенно появится результат.
3. Сравните эквализацию `RGB` и `HSV: только V` на `01_color_low_contrast`.
4. Для `03_outliers_gray` сравните растяжение и эквализацию; для `06_uniform_gray` проверьте отсутствие деления на ноль.
5. Переключайте канал гистограммы. Обе гистограммы имеют единый максимум по Y.

Кнопка «Скачать тестовый набор PNG» генерирует шесть файлов из `testGenerator.js`; при необходимости поместите их в `test_images/`. Для отчёта откройте `report.html` и распечатайте в PDF: вёрстка состоит ровно из двух A4-страниц.
