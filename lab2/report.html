Лабораторная работа № 2. Вариант 1

Поэлементные операции, линейное контрастирование и эквализация гистограммы

Цель. Реализовать методы точечной обработки изображений и методы повышения контраста по гистограмме; сравнить их на контролируемых тестовых изображениях.

Задача. Разработать веб-приложение, которое рассчитывает результат каждого метода из неизменённого исходника, отображает гистограммы до и после обработки и сохраняет PNG.

Поэлементные операции

Для каждого значения канала f∈[0;255] вычисляется g, затем применяется clip(x,0,255) — округление и ограничение диапазоном. Реализованы:

яркость: g=clip(f+c,0,255), c∈[−150;150];  контраст: g=clip(round(f·k),0,255), k∈[0,1;3];

негатив: g=255−f;  логарифм: g=clip(round(c·ln(1+f)),0,255);

гамма: g=clip(round(255·(f/255)γ),0,255), γ∈[0,1;5].

Для логарифма коэффициент выбирается как c=255/ln(1+maxf), поэтому максимальный уровень переходит в 255; ручной коэффициент также доступен. При f=50 гамма 0,5 даёт 113, гамма 2 — 10. При f=200 получаются 226 и 157. Следовательно, γ<1 усиливает тёмные области, γ>1 ослабляет пересвет.

Гистограмма и контрастирование

Гистограмма h(i) — число пикселей уровня i. В полутоновом режиме используется Y=round(0,299R+0,587G+0,114B). Для обоих графиков выбирается общий максимум по оси Y, поэтому видна реальная разница высоты столбцов.

Линейное растяжение. T(i)=round(255·(i−min)/(max−min)). Уровень min переходит в 0, max — в 255. При min=max преобразование не выполняется, чтобы исключить деление на ноль. Для цветного режима та же формула применяется к V в HSV с сохранением H и S; для сравнения доступен независимый режим RGB.

Эквализация. T(i)=round(255·C(i)/N), где C(i)=h(0)+…+h(i), N — число пикселей. Одноуровневая гистограмма сохраняется. В RGB строятся три независимые таблицы, поэтому оттенок может измениться. В HSV строится одна таблица V=max(R,G,B); H и S сохраняются, при V=0 результат остаётся чёрным.

Ручной расчёт

Для уровней 80, 100, 120 растяжение даёт 0, 128, 255. При долях 60%, 30%, 10% накопленные доли равны 0,60; 0,90; 1,00. Эквализация по формуле из лекции даёт 153, 230, 255. Растяжение использует только границы диапазона, эквализация использует частоты всех уровней.

Особенности реализации

Пиксели хранятся в ImageData. Каждая операция получает копию исходного массива, поэтому последовательные переключения методов не накапливают ошибку округления. Эквализация RGB строит по одной таблице для каждого канала; HSV(V) преобразует RGB→HSV, заменяет V по таблице и выполняет обратное преобразование. Гистограмма доступна для Y, R, G, B и V.

Порядок проверки
  1. Выбрать тест или загрузить собственный файл; слева отображается неизменённый исходник, справа — результат.
  2. На 04 сравнить логарифм и γ<1, на 05 — γ>1 и добавление отрицательной константы.
  3. На 02 и 03 сравнить растяжение и эквализацию. На 01 переключить RGB и HSV(V).
  4. Переключить канал гистограммы Y/R/G/B/V и проверить общую вертикальную шкалу.
  5. Нажать «Сохранить результат PNG»; набор из шести образцов скачивается отдельной кнопкой.
Вывод

Поэлементные операции изменяют уровень независимо и полезны для коррекции экспозиции. Линейное растяжение чувствительно к крайним уровням и выбросам. Эквализация зависит от распределения яркости, поэтому изменяет основную массу пикселей при тех же границах. Обработка V в HSV повышает контраст без независимой коррекции цветовых каналов.
