# Тестовый набор

PNG-файлы не хранятся в репозитории: они детерминированно создаются из `testGenerator.js` прямо в браузере. Нажмите «Скачать тестовый набор PNG» в приложении: браузер сохранит шесть файлов с именами `01_...png` — их можно поместить в эту папку перед коммитом, если преподавателю нужны физические образцы.
