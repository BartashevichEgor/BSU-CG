# Защита ЛР №3 — базовые растровые алгоритмы

## Что открыть преподавателю

1. Открой `http://localhost:8000/lab3/` и включи галочку «Показать идеальную линию».
2. Нажми пресет `(0,0) → (5,2)`. Таблица показывает, из каких вычислений получились клетки.
3. Последовательно выбери «Пошаговый», «ЦДА», «Брезенхем: отрезок». Клетки должны совпасть, но сопроводительные значения разные.
4. Введи `(5,2) → (0,0)`, затем вертикаль `(0,0) → (0,5)`, затем точку `(2,3) → (2,3)`.
5. Выбери окружность, введи `r=0`, затем `r=4` и покажи отсутствие дубликатов на диагоналях.

## Алгоритмы словами

### Пошаговый

```text
N = max(abs(x1-x0), abs(y1-y0))
если N == 0: вернуть (x0,y0)
для i = 0..N:
  x = round(x0 + i*(x1-x0)/N)
  y = round(y0 + i*(y1-y0)/N)
```

Сильная сторона: любую клетку легко проверить отдельно. Минус: деление и округление на каждом шаге.

### ЦДА

```text
dx = (x1-x0)/N; dy = (y1-y0)/N
x = x0; y = y0
N+1 раз: записать round(x), round(y); x += dx; y += dy
```

Разница с пошаговым: дробные координаты накапливаются, а не вычисляются заново.

### Брезенхем для отрезка

```text
a=abs(dx); b=abs(dy); sx=sign(dx); sy=sign(dy); e=a-b
пока не достигнут конец:
  записать (x,y)
  d=2*e
  если d > -b: e-=b; x+=sx
  если d <  a: e+=a; y+=sy
```

Главное: внутри цикла только целые числа. Две проверки могут обе сработать — это диагональный шаг.

### Брезенхем для окружности

```text
x=0; y=r; e=3-2*r
пока x <= y:
  добавить 8 симметричных точек
  если e < 0: e += 4*x + 6
  иначе: e += 4*(x-y) + 10; y--
  x++
```

Семь отражений экономят вычисления. `Set` удаляет совпадения, когда x=0 или x=y.

## Вопросы, которые вероятны

**Почему Y направлена вверх, хотя Canvas направляет вниз?** В `gridCanvas.js` экранная координата вычисляется как `cy - y * cell`; минус разворачивает Y в математическое направление.

**Почему точка в центре клетки?** Так клетка однозначно представляет целочисленную координату; её границы находятся на ±0,5.

**Почему ЦДА может накопить ошибку?** x и y прибавляются дробными значениями много раз. Конечная точка записывается явно.

**Почему Брезенхем работает в любом октанте?** `sx` и `sy` задают направление шагов, а `a` и `b` всегда неотрицательны.

**Почему нельзя сравнивать время через Canvas?** Canvas измеряет ещё рисование и браузер; benchmark.js измеряет только вычислительные циклы через `process.hrtime.bigint()`.
