# Лабораторная работа №3 — базовые растровые алгоритмы

Веб-приложение на чистом Canvas 2D показывает растровые клетки в математической системе координат: X вправо, Y вверх, а целочисленная точка лежит в центре клетки.

## Запуск приложения

Из корня репозитория запустите `python -m http.server 8000`, затем откройте `http://localhost:8000/lab3/`. Сторонние библиотеки и сборщик не требуются.

## Что реализовано

- пошаговый алгоритм отрезка;
- ЦДА / DDA;
- целочисленный Брезенхем для отрезка всех октантов;
- целочисленный Брезенхем для окружности с устранением повторов симметричных точек;
- бонус: сглаженная линия Ву и Castle–Pitway со строкой `s`/`d`;
- таблица шагов, идеальная геометрия, масштаб сетки, координаты наведения и быстрый браузерный замер.

## Консольный бенчмарк

```powershell
node lab3/benchmark.js
```

Скрипт прогревает V8 и измеряет только вычислительные циклы: Canvas и создание объектов клеток в замер не входят. Результаты зависят от компьютера, поэтому в отчёт надо переносить числа, полученные на своей машине.

## Проверка на защите

Используйте пресет `(0,0) → (5,2)` для таблиц шагов. Затем проверьте обратное направление, вертикаль, горизонталь и точку `(x0,y0)=(x1,y1)`. Для окружности проверьте `r=0`, `r=1`, точки на осях и диагонали: клеток-дубликатов быть не должно.
