Лабораторная работа № 3
Базовые растровые алгоритмы

Цель работы

Целью работы является исследование и сравнение алгоритмов растеризации отрезка и окружности, их математических инвариантов, поведения на граничных данных и вычислительных характеристик. Программный прототип используется для экспериментальной проверки последовательностей клеток и времени чистых вычислений.

Задачи работы

  1. Сопоставить пошаговый алгоритм, ЦДА и целочисленный Брезенхем для всех октантов.
  2. Исследовать восьмикратную симметрию окружности Брезенхема и отсутствие повторов.
  3. Проверить горизонталь, вертикаль, отрицательные направления, вырожденный отрезок и r=0.
  4. Сравнить время алгоритмов без влияния отрисовки.

1. Растеризация и система координат

Геометрический отрезок и окружность являются непрерывными объектами, однако экран состоит из конечного числа дискретных пикселей. Растеризация — это выбор набора клеток сетки, которые лучше всего приближают непрерывную фигуру. В данной работе целочисленная координата (x,y) располагается строго в центре клетки. Следовательно, клетка представляет область [x−0,5;x+0,5]×[y−0,5;y+0,5].

В Canvas экранная ось Y по умолчанию направлена вниз. Для соответствия математической системе в приложении используется преобразование экранной координаты:

screenX=centerX+x·cell,   screenY=centerY−y·cell.

Знак минус во втором выражении разворачивает ось Y вверх. Сетка показывает оси, стрелки, подписи делений и координаты клетки под курсором.

2. Пошаговый алгоритм

Пусть заданы концы отрезка (x0,y0) и (x1,y1). Сначала находятся приращения:

Δx=x1−x0,   Δy=y1−y0,   N=max(|Δx|,|Δy|).

Если N=0, оба конца совпадают и возвращается одна клетка. Иначе для каждого i от 0 до N точка вычисляется независимо:

x=round(x0+i·Δx/N),   y=round(y0+i·Δy/N).

Преимущество метода — простота ручной проверки любой точки. Недостаток — деление и округление выполняются на каждом шаге.

3. Алгоритм ЦДА

ЦДА использует то же N, но дробные приращения вычисляет один раз:

dx=Δx/N,   dy=Δy/N.

x=x0; y=y0
для i от 0 до N:
    записать клетку round(x), round(y)
    x=x+dx; y=y+dy

В отличие от пошагового метода дробные координаты накапливаются. Это быстрее с точки зрения формулы, но при длинных отрезках может возникать накопление погрешности float. Поэтому последняя клетка в программе принудительно заменяется точной конечной точкой.

4. Алгоритм Брезенхема для отрезка

Брезенхем выбирает ближайшую клетку с помощью целочисленной переменной ошибки. Для всех направлений вводятся:

a=|Δx|,   b=|Δy|,   sx=sign(Δx),   sy=sign(Δy),   e=a−b.

пока не достигнут (x1,y1):
    записать (x,y)
    d=2e
    если d > −b: e=e−b; x=x+sx
    если d <  a: e=e+a; y=y+sy

Внутри цикла нет ни деления, ни вещественных чисел. Две проверки не являются ветвями else: если прямая проходит диагонально, обе выполняются и меняются сразу x и y. Значения sx и sy обеспечивают правильную работу при отрицательных координатах, обратном направлении, вертикали и горизонтали.

5. Алгоритм Брезенхема для окружности

Окружность обладает восьмикратной симметрией. Алгоритм вычисляет точку одного октанта и отражает её относительно осей и диагоналей. Начальные значения:

x=0,   y=r,   e=3−2r.

пока x ≤ y:
    добавить 8 симметричных точек
    если e < 0: e=e+4x+6
    иначе: e=e+4(x−y)+10; y=y−1
    x=x+1

На осях при x=0 и на диагонали при x=y несколько отражений дают одну и ту же клетку. В реализации координаты добавляются через Set, поэтому дубликаты не попадают в результат. Для r=0 цикл возвращает единственную клетку центра.

7. Дополнительные алгоритмы

Алгоритм Ву строит сглаженный отрезок. Вместо выбора только одной клетки для каждого шага он распределяет интенсивность между двумя соседними клетками. Альфа-значение пропорционально расстоянию до идеальной прямой, поэтому визуально линия выглядит менее ступенчатой.

В дополнительном режиме Castle–Pitway последовательность осевых и диагональных движений представляется строкой. Символ s означает шаг только по главной оси, d — диагональный шаг. Для (0,0)→(5,2) отображается строка sdsds. Она полезна для объяснения того, как наклон линии задаётся дискретным набором ходов.

8. Методика измерения времени

Замеры выполняются в Node.js через process.hrtime.bigint() после прогрева V8. Для N=1000, 100000 и 10000000 используются отрезки (0,0)→(N−1,round(0,4·(N−1))); Canvas и создание объектов клеток исключены, поэтому измеряется только вычислительная часть алгоритмов.

Вывод

Пошаговый алгоритм даёт прозрачную формулу для любой точки, но выполняет деление и округление на каждом шаге. ЦДА уменьшает число делений, однако накапливает дробные приращения. Брезенхем для отрезка сохраняет целочисленный инвариант ошибки и корректно проходит все октанты; это подтверждают граничные испытания. Для окружности использование восьмикратной симметрии даёт наименьшее измеренное время: 22,127 мс против 138…166 мс на самом крупном тесте, однако числа относятся к разным геометрическим объектам и сравнивают вычислительную схему, а не одинаковый набор клеток.
