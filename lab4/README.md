# Лабораторная работа №4 — отсечение

Откройте `index.html` в браузере. Приложение не требует установки библиотек и работает локально.

## Вариант 1

1. Отрезки отсекаются алгоритмом Сазерленда—Коэна. Для каждой конечной точки строится четырёхбитный код положения относительно окна: `L=0001`, `R=0010`, `B=0100`, `T=1000`. Равенство `(code0 | code1) = 0` означает полное принятие; ненулевое `(code0 & code1)` — тривиальное отклонение. Иначе внешняя точка заменяется пересечением прямой `P(t)=P0+t(P1−P0)` с соответствующей стороной окна.
2. Выпуклый многоугольник отсекается алгоритмом Сазерленда—Ходжмена: его вершины последовательно пропускаются через четыре полуплоскости прямоугольного окна. При переходе «внутри ↔ снаружи» в список добавляется точка пересечения ребра с границей.

## Формат входа

Для отрезков: первая строка — `n`, следующие `n` строк — `x1 y1 x2 y2`, последняя — `xmin ymin xmax ymax`.

Для многоугольника: первая строка — `m`, следующие `m` строк — `x y` вершин в обход контура, последняя — координаты окна. Многоугольник должен быть выпуклым.

Комментарии после `#` игнорируются. В таблице справа отображаются именно промежуточные вычисления выбранного алгоритма.
